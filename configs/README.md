## English

[**Russia.conf · v2.0 Beta**](Russia.conf) is included with content identical to the user-supplied `Shadowrocket-Russia-v2.0-Beta.conf`. Its 340 rules have been statically reviewed; Shadowrocket import and Russian network behavior have not been tested.

[Download the original Raw file](https://raw.githubusercontent.com/Emptydesire/Shadowrocket-RU-CN-Routing/main/configs/Russia.conf)

This repository focuses on use in Russia, including direct routing for Chinese services. The China-mode configuration will be open sourced separately and is outside this repository. No proxy nodes, accounts, or node subscriptions are supplied.
